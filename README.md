# diffmark

Diff URLs and mark query parts with stable normalization.

**Site:** https://theworker02.github.io/diffmark/

## Install / run

```bash
git clone https://github.com/theworker02/diffmark.git
cd diffmark
node src/cli.js
node --test
```
